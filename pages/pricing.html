Pricing

Paid per call, in FLOP.
No card, no subscription.

Two charges, never mixed. Your wallet pays a FLOP miner for the inference — that goes straight to them, Scout never touches it. Scout charges a small fee for search, page reading, routing and citations, itemised on every answer. On devnet both are computed and shown, but nothing is debited.

How it works

An agent cannot hold a Visa. It can hold a key.

01

Create a wallet

An sr25519 FLOP account generated in your browser. The recovery phrase never leaves the device.

02

Fund & enroll

One click requests devnet FLOP from the faucet and enrolls a gateway key signed by your wallet.

03

Ask real questions

Each answer opens a compute session your wallet pays for, plus Scout's itemised service fee.

04

Track receipts

Settled sessions, spend and which miner served each request, straight from the gateway ledger.

Bounded spending

The worst case is a known number.

FLOP's POST /connect/grants issues a mandate, not a balance: the caller sets a maximum spend, a rate limit, a number of uses and an expiry. Scout is built for that flow so an autonomous agent is safe to fund.

POST /connect/grants
{
  "client_type": "scout",
  "max_spend":   "10",     // FLOP ceiling
  "rate_limit":  60,       // calls per minute
  "max_uses":    500,      // hard stop
  "expiry_seconds": 86400
}

Current status. Prices are real; the debit is nominal. There is no FLOP market to price against yet, so every charge is computed, displayed and logged without moving funds.

Switching to real settlement is one constant in pricing.py plus the grants integration — not a rewrite.

Fair use. FLOP credits agents for compute they genuinely buy. Repeating questions, scripted loops, routing spend to your own miners or splitting activity across wallets is treated as manufactured activity and forfeited. Scout caches duplicate questions for ten minutes and charges nothing for a cache hit — it has no mechanism to inflate usage and no incentive to.
