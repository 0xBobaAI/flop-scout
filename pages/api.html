API

One endpoint.
Made to be called by agents.

Search the sources you choose, answer with a model you choose, get citations and an itemised FLOP price back. No SDK, no signup — a POST and a JSON body.

Ask

The one call you actually need.

POST /api/answer
Content-Type: application/json

{
  "q": "Which FLOP miners are most reliable?",
  "sources": ["explorer_reliability", "flop_stats"],
  "model": "flop:qwen/qwen2.5-0.5b-instruct",
  "n": 3,
  "max_tokens": 250,
  "keys": { "flop": "<your gateway key>" }
}

Endpoints

Everything else is a GET.

EndpointReturns
POST /api/answersearch → cited answer → receipt, with an itemised FLOP price
GET /api/pricingthe full service catalogue and current metering mode
GET /api/catalogsources, presets and models
GET /api/routerlive miner ranking with scores
GET /api/minersevery miner with GPU, stake and router score
GET /api/statsper-model success rate, payer split, accruals
GET /api/healthliveness and whether a gateway key is present

Errors

What comes back when it goes wrong.

Sources and pricing still render when the model fails, so a partial answer is always usable.

StatusMeaningWhat to do
429 rate_limit_exceededThe devnet gateway is throttlingBack off; Scout already retries inside a 200s budget
429 miner_capacity_reservedEvery miner is at capacityCapacity frees in seconds — retry shortly
503 / 524Origin timeout at the gatewayCongestion, not your request; sources still return
401 model_not_allowedYour key is not scoped for that modelNew devnet keys get qwen2.5-0.5b only
422Request validation failedq 2–500 chars, n 1–8, max_tokens 32–800

Limits

Deliberately low, on purpose.

20

answers / day

Per IP on Scout's own wallet. Connect a wallet to lift it.

6

answers / minute

Per IP when you bring your own gateway key.

10 min

duplicate window

Same question returns the cached answer, free, without a new session.

6

sources / call

Run in parallel, merged and deduped by URL, capped at 12 results.
